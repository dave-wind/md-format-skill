# 中国三大云厂商 2024 年对比

## 市场份额

| 厂商 | 份额 |
|------|------|
| 阿里云 | 33% |
| 华为云 | 19% |
| 腾讯云 | 16% |
| 其余厂商 | 32% |

## 核心能力对比

| 厂商 | 基因与定位 | 核心优势 |
|------|-----------|---------|
| **阿里云** | 电商基因 | 大数据生态最完善（MaxCompute、DataWorks），国际化布局最广（29 个 Region） |
| **华为云** | 政企市场强势 | 自研芯片昇腾 + 鲲鹏，混合云方案成熟 |
| **腾讯云** | 社交 / 游戏基因 | 音视频能力突出（TRTC），与微信生态深度整合 |
