# 机器学习模型评估指标总结

## 分类指标

| 指标 | 公式 |
|------|------|
| 准确率 (Accuracy) | (TP + TN) / (TP + TN + FP + FN) |
| 精确率 (Precision) | TP / (TP + FP) |
| 召回率 (Recall) | TP / (TP + FN) |
| F1 Score | 2 × Precision × Recall / (Precision + Recall) |

### 类别不均衡问题

当类别不均衡时（比如欺诈检测，正样本仅占 0.1%），Accuracy 没有意义。

**示例：** 假设 10000 个样本中 10 个正样本，如果模型全部预测为负：

- **Accuracy** = 9990 / 10000 = 99.9%（看似很高）
- **Recall** = 0 / 10 = 0%（完全没检出）

## 回归指标

| 指标 | 公式 |
|------|------|
| MSE | (1/n) × Σ(yᵢ - ŷᵢ)² |
| RMSE | √MSE |
| MAE | (1/n) × Σ\|yᵢ - ŷᵢ\| |
| R² | 1 - Σ(yᵢ - ŷᵢ)² / Σ(yᵢ - ȳ)² |

> **R² 的含义：** 模型解释了多少比例的方差。R² = 0.85 意味着模型解释了 85% 的数据变异。

## 模型对比（某金融风控场景）

| 模型 | AUC | 推理延迟 | 可解释性 |
|------|-----|----------|----------|
| 逻辑回归 | 0.82 | 2ms | 高 |
| XGBoost | 0.91 | 5ms | 中等 |
| 深度学习 | 0.93 | 50ms | 低 |

### 选择建议

- 如果业务要求**可解释性**（如银行合规） → 选逻辑回归或 XGBoost
- 追求**纯性能**且延迟不敏感 → 选深度学习
